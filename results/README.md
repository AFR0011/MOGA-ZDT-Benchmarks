# Archived benchmark results

These CSV files preserve the quantitative record used in the repository summary, figures, and study report.

- `summary_full_comparison.csv` contains the GD/IGD comparison for all five algorithms across ZDT1, ZDT2, ZDT3, ZDT4, and ZDT6 at D=10 and D=30.
- `overall_ranking.csv` aggregates performance across all tested problem/dimension cases.
- `front_size_summary.csv` summarizes the mean final nondominated front size.
- `hyperparameter_sensitivity.csv` records the strongest tested sensitivity profile for each algorithm.
- `gd_*` and `igd_*` files provide dimension-specific tables.

The archived values are treated as the authoritative record of the completed full experiment. Fresh reruns should be written to a separate output directory rather than overwriting these files.
